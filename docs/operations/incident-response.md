# Incident Response

## Severity model

- P1: Immediate response, 24/7 coverage
- P2: Respond within 1 hour
- P3: Respond the same business day
- P4: Address in the next sprint

## Response steps

1. Declare the incident severity.
2. Notify the on-call owner and stakeholders.
3. Contain the impact and preserve evidence.
4. Mitigate the issue and validate recovery.
5. Document the incident and follow up with corrective actions.
