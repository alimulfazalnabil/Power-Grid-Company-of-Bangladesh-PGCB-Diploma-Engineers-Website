# Production Launch Checklist

## Infrastructure

- [ ] Terraform applied successfully
- [ ] AKS cluster is healthy
- [ ] Private networking is verified
- [ ] Key Vault is populated
- [ ] Monitoring and alerting are active

## Security

- [ ] WAF is enabled
- [ ] RBAC is verified
- [ ] Workload Identity is configured
- [ ] Container images are signed
- [ ] Vulnerability scans passed

## Application

- [ ] Database migrations completed
- [ ] Initial admin account created
- [ ] Storage containers verified
- [ ] Background workers are running
- [ ] Email and notification services configured

## Operations

- [ ] Backups verified
- [ ] Restore tested
- [ ] Runbooks reviewed
- [ ] Dashboards available
- [ ] On-call contacts assigned
