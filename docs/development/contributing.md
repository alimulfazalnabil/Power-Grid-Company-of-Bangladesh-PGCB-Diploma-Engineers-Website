# Contributing Guide

## Development workflow

1. Create a feature branch.
2. Implement the change with tests where appropriate.
3. Run linting and relevant tests.
4. Open a pull request for review.
5. Merge after CI and security checks pass.

## Review expectations

- Keep changes focused and well-documented.
- Include operational impact notes for infrastructure and deployment changes.
- Ensure release-readiness artifacts are updated when behavior changes.
